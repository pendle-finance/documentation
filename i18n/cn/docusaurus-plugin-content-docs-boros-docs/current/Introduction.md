# Boros 概览

Boros 是 Pendle 旗下的保证金利率交易平台。每个 Boros 市场追踪一个浮动利率，让您以该利率与固定利率进行交易，直至到期。任何拥有可靠预言机数据的利率，都可以作为市场上线。

Boros 最初推出的是来自中心化与去中心化永续合约交易所的资金费率市场。如今，Boros 还上线了**价差市场（Spread Market）**，用于交易两个资金费率之间的差值。未来还将支持更多类别的利率。

![Boros Overview](/img/boros-overview.png)

通过期现套利捕捉资金费率，是 TradFi 与加密世界中的常见策略。Boros 是首个让您直接交易这些利率*变动*的协议，其 YU（收益单位）市场开启了全新一类的收益策略。

Boros 内有 3 个主要组成部分：

### 1. 利率核算

在交易某个利率之前，Boros 需要先获取该利率本身。Boros 通过预言机读取每个利率，例如 Binance BTCUSDT 资金费率或 Hyperliquid HYPEUSDC 资金费率。这被称为**底层 APR（Underlying APR）**，因为它是底层资产或交易场所的利率。

<Hint style="info">
只要某个利率有预言机数据，它就可以在 Boros 上受到支持，包括由其他利率组合而成的利率，例如两家交易所资金费率之间的价差。
</Hint>

### 2. 利率交易（YU 交易）

**Boros 通过将浮动利率流表示为 YU（收益单位）来实现利率交易。** 每个 YU 代表 1 单位抵押资产所赚取的浮动利率。

例如，在以 BTC 为抵押品的 BTCUSDT（Hyperliquid）市场中，每个 YU 代表 Hyperliquid 上 1 BTC 的资金费率。在 BTC Spread HL-Gate 市场中，每个 YU 代表 1 BTC 的 Hyperliquid 减 Gate 资金费率价差。

### 3. 保证金、清算和风险参数

要在 Boros 上开设头寸，您需要以市场的抵押资产存入抵押品，然后开设多头或空头头寸。如果您的净余额低于维持保证金，该头寸可能被清算。

无论市场追踪的是哪种利率，交易、保证金、结算与清算规则都完全相同。

## 市场类型

Boros 目前有两种市场类型。您可以在市场页面通过「**资金费率**」("Funding") 与「**价差**」("Spread") 标签进行切换。

- **[资金费率市场](./about-boros/market-types#funding-markets)**：底层利率是单个永续合约市场的资金费率，例如 Binance BTCUSDT。
- **[价差市场](./about-boros/spread-markets)**：底层利率是同一资产在两家交易所的资金费率之差，例如 Hyperliquid BTC 资金费率减去 Gate BTC 资金费率。

关于每种类型的定义与结算方式，请参阅[市场类型](./about-boros/market-types)。

## 使用场景

1. **押注利率方向**
预期资金费率将上升的交易者可以做多 YU。该头寸以固定流支付隐含 APR，并接收浮动的底层利率。如果浮动利率最终高于固定利率，交易者即可获利。
2. **对冲资金费率支付**
Binance 上的 BTC/USDT 永续合约交易者可以将浮动的资金费率支付转换为固定支付。为此，他们可以做多 YU-BTCUSDT（Binance），支付固定流并接收浮动资金费率。**其结果是资金成本被固定至到期。**
3. **为期现套利锁定固定收益**
期现套利头寸从永续合约市场收取浮动资金费率。交易者可以通过做空 YU 锁定当前利率，即支付浮动流并接收固定流。组合头寸在到期前赚取固定收益。
4. **交易跨平台资金费率价差**
同一资产在不同永续合约交易场所的资金费率往往存在差异。**[价差市场](./about-boros/spread-markets)** 让您以单一头寸交易这一差值：
    - **做空价差**，将当前价差锁定为固定利率。配合在高资金费率场所做空永续合约、在低资金费率场所做多永续合约，即可将跨交易所套利锁定为无价格敞口的固定回报。[使用 CrossEx 套利](./arbitrage-with-crossex/overview)可自动执行这一策略。
    - **做多价差**，押注两家交易所之间的价差将扩大。

    对于没有价差市场的交易场所组合，您可以用两个资金费率市场头寸构建相同的敞口：在高资金费率场所做空 YU，在低资金费率场所做多 YU。

## 为什么交易利率？

永续合约是加密领域交易最活跃的工具之一。每个永续合约头寸都会支付或收取资金费率，但在 Boros 出现之前，从未有场所可以直接交易这一利率。Boros 让交易者能够精准把控这一敞口，并将同样的机制扩展到任何拥有预言机数据的利率，首先是交易场所之间的价差。

**使用 Boros 主要有三种方式：**

- 做多或做空某个利率，表达对其走向的看法
- 将 YU 头寸与已有的永续合约头寸配对，把浮动的资金费率支付或应收转换为固定利率
- 在价差市场上以单一头寸，将两家交易所之间的利率差锁定为固定收益
