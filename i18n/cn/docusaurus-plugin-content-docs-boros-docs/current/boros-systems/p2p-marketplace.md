# P2P 市场

P2P 市场让你直接与交易对手协商约定规模的利率互换交易，而无需通过订单簿成交。

由于交易在场外达成并在固定时间执行，你可以获得：

- **任意规模** — 不受订单簿深度限制
- **你的条款** — 利率、规模和执行时间均由你协商
- **无价格冲击** — 交易不会扫穿订单簿

![Marketplace](/boros-docs/imgs/p2p-marketplace/browse-marketplace.png "Marketplace")

## 两种角色

| 角色 | 职责 |
| --- | --- |
| **Maker（挂单方）** | 发布挂单，即公开的交易意向。 |
| **Taker（吃单方）** | 浏览挂单，并针对某个挂单提交实盘报价。 |

两种角色你都可以担任。**Maker** 发布交易意向；**Taker** 提出具体条款。

## 流程概览

1. Maker **发布挂单**（市场、方向、指示性 APR、最小规模、有效期）。
2. Taker 针对该挂单**提交报价**，包含具体的规模、APR 和执行时间。
3. Maker **接受、还价或拒绝**。
4. 若为还价，则相当于把球传回给对方，对方可以接受、再次还价或拒绝。如此往复，直到一方接受或拒绝为止。
5. 一旦接受，**双方即受约束**。交易将在约定时间自动执行。

每当你提交报价或还价时，都会锁定一笔小额 **bond（保证金债券）**作为诚信押金。无论报价最终是执行、被拒绝、被取消还是过期，该 bond 都会在报价了结后退回。详见 [Bond 与惩罚](#bonds-and-penalties)。

:::note
还价**不会**改变你的 Maker 或 Taker 角色。在整个协商过程中，Maker 始终是 Maker，因此支付费用的一方也不会改变。还价仅仅意味着轮到对方回应了。
:::

## 发布挂单

点击 **Create a listing**，并设置：

| 字段 | 含义 |
| --- | --- |
| **市场** | 你想交易的市场。 |
| **方向** | 做多或做空利率。 |
| **指示性 APR** | 你希望围绕成交的 APR。**不具约束力**，它只是一个信号，而非价格。Taker 可以按任意 APR 报价。 |
| **最小规模** | 你愿意考虑的最小报价规模。 |
| **挂单有效期** | 挂单保持可见的时长。 |
| **保证金账户** | 全仓或逐仓。若在接受时你已在该市场持有仓位，则使用该仓位所在账户。 |

![Create new listing](/boros-docs/imgs/p2p-marketplace/list-new-deal.png "Create new listing")

发布挂单不产生任何成本，也不构成任何承诺。你可以随时取消未成交的挂单，且无任何惩罚。

## 提交报价

浏览市场，选择一个挂单，点击进入并提交报价。与挂单不同，报价是一个**实盘报价**：

| 字段 | 含义 |
| --- | --- |
| **报价 APR** | 你实际希望成交的利率。默认为指示性 APR，但你可以报任意价格。 |
| **规模** | 你希望交易的 YU 数量。 |
| **执行时间** | 交易在链上触发的确切时间。通常设置在资金费率结算之前。 |
| **给 Maker 的留言** | 可选，随报价一同发送的消息。 |

![Place an offer](/boros-docs/imgs/p2p-marketplace/make-offer.png "Place an offer")

提交时，系统会从你的保证金账户锁定一笔 **bond**。确认前，面板会显示 bond 金额。

在报价被接受之前，你**可以随时取消待处理的报价**，且无任何惩罚，bond 将全额退回。

## 回应报价

当有人对你的挂单提交报价时，你有三种选择：

![Respond to an offer](/boros-docs/imgs/p2p-marketplace/respond-offer.png "Respond to an offer")

| 操作 | 结果 |
| --- | --- |
| **接受（Accept）** | 交易即具约束力。条款被锁定，并将在约定时间执行。 |
| **还价（Counter）** | 你提出自己的条款。接下来由对方决定接受、再次还价或拒绝。 |
| **拒绝（Reject）** | 该报价作废，对方的 bond 被释放。 |

不作回应也是一种选择。若在执行时间前未被接受，报价会自动过期。

### 还价

还价本质上就是按你自己的条款提出的一个**全新报价**。你可以修改三项可协商条款中的任意一项：**APR、规模和执行时间**。

![Counter an offer](/boros-docs/imgs/p2p-marketplace/counter-offer.png "Counter an offer")

还价会为你的新报价锁定一笔完整的 bond，而被替代的那笔报价的 bond 会退回给对方。

协商可以来回进行任意多轮，直到一方接受（具约束力）或拒绝（作废）为止。

:::info
接受是**针对报价规模的全有或全无**。不存在部分成交，如果你只想要其中一部分规模，请按较小规模还价。
:::

## 接受之后

一旦接受，**规模、APR 和执行时间**这三项条款即被彻底锁定。双方均无法反悔。

从接受到执行期间，你要做的很简单：**确保你的保证金账户有足够的抵押品**。

- 交易将在约定时间**自动执行**。你无需在线。
- 若双方都已备足资金并准备就绪，任意一方均可点击 **Ready to execute**。当双方都发出就绪信号时，交易会提前执行。
- 保证金是**账户层面共享的**，并非按报价逐笔锁定。你只需整体补充一次，**My Trades** 标签页会按账户显示所需保证金总额与可用保证金。

![My Trades](/boros-docs/imgs/p2p-marketplace/offers-tab.png "My Trades")

:::warning
显示的所需保证金是**估算值**。确切金额取决于执行时的标记 APR。请预留缓冲。
:::

## Bond 与惩罚 {#bonds-and-penalties}

Bond 是为保证协商诚信而锁定的抵押品。它是**冻结而非转移**的，且远小于该仓位所需的完整保证金。

以下情况**你的 bond 会被释放**：

- 你的报价被拒绝、取消、还价或过期
- 交易成功执行

以下情况**你的 bond 会被罚没**：你**先接受后违约**，即你已受交易约束，却在执行时没有足够保证金来履约。被罚没的 bond 将作为补偿支付给你的交易对手。

这是唯一会受到惩罚的行为。以下情况**不会有任何惩罚**：

- 让你的挂单过期
- 取消挂单中未成交的部分
- 拒绝或忽略报价
- 在报价被接受前取消自己的报价
- 让自己的报价在被接受前过期

### 注意保证金预警

若某笔报价即将执行而你的保证金不足，该报价行及对应账户上会出现**预警提示**。如果你已开启通知，还会收到 Telegram 提醒。请在执行时间前补足保证金，以免损失 bond。

## 报价／交易状态

| 状态 | 含义 |
| --- | --- |
| **Pending（待处理）** | 有效报价，尚未被处理。可以取消。 |
| **Countered（已还价）** | 对方提出了不同条款。请回应，或任其过期。 |
| **Accepted（已接受）** | 具约束力。执行时间已锁定。请确保保证金充足。 |
| **Executed（已执行）** | 仓位已在链上开立。Bond 已释放。 |
| **Rejected（已拒绝）** | 被对方拒绝。Bond 已释放。 |
| **Cancelled（已取消）** | 在被接受前撤回。Bond 已释放。 |
| **Expired（已过期）** | 未在时限内被接受。Bond 已释放。 |
| **Failed（已失败）** | 已接受但未能执行，通常是因为一方保证金不足。违约方的 bond 将被罚没并支付给另一方。 |

你发布的挂单位于 **My Listings**，你参与的报价与交易位于 **My Trades**。这两个标签页默认显示活跃记录；已完成的记录会移至 **Inactive** 标签页。

## 费用

P2P 交易支付**标准的 taker 费率（5 bps）**。合约仅允许单方支付，因此目前由 **Maker**（发布挂单的一方）承担费用。

## 须知事项

- **执行时间很重要。** 它通常设置在资金费率结算之前，请审慎选择。
- **接受后即可对冲。** 由于接受具有约束力且违约方需作出补偿，交易一经接受，你就可以放心地建立对冲。
- **报价无法修改。** 若要更改条款，请取消后重新提交，或使用还价。
- **YU 不能用作保证金。** 请为 P2P 交易存入新的抵押品。
- **大额交易可能需要风控审核。** 大多数接受操作会自动通过，但触发成交量或规模上限的交易将转入人工审核，应用内显示为 *Pending Approval*。
- **取消挂单 ≠ 取消已接受的交易。** 已被接受的报价仍会照常执行。
