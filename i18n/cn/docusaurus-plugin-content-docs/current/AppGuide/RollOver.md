# 展期

市场到期后，你的 PT 不再增值，LP 也不再赚取固定收益。资金仍然属于你，但在你采取行动前会一直闲置。**展期**（Roll Over）让你在单笔交易中把已到期的 PT 或 LP 头寸转入新市场，无需先兑换回底层资产。

## 到期后会发生什么

你的头寸是安全的，可以随时兑换，但已经停止产生收益：

* **PT** 可按 1:1 兑换为会计资产。它不再增值，因此每多放一天，就多损失一天的收益。
* **LP** 不再从 PT 获得固定收益。已累积的奖励仍可领取。
* **YT** 已到期，价值为零。

> 假设你持有价值 $10,000 的已到期 PT，而同一资产的下一个市场提供 8% 的固定 APY，那么晚一周展期大约会损失 $15 的收益。

## 到期后展期

市场到期后，头寸页面会显示两个操作：「**展期**」("Roll Over") 和「**全部赎回**」("Redeem All")。

![已到期头寸](/pendle-docs/imgs/AppGuide/roll-over/position-matured.png "已到期头寸")

1. 前往 [Dashboard](https://app.pendle.finance/trade/dashboard/overview/positions)，打开已到期的资产。
2. 点击「**展期**」。若选择「**全部赎回**」，则会退出到你指定的代币。
3. 选择目标市场。标记为「**同类市场**」("Similar Market") 的市场底层资产相同，但到期日更晚。

    ![选择目标市场](/pendle-docs/imgs/AppGuide/roll-over/select-market.png "选择目标市场")

4. 选择要展期的头寸（PT、LP 或两者）及各自的数量。开启「**领取 LP 奖励**」("Claim LP Rewards") 可将已累积的奖励并入同一笔交易。
5. 选择在目标市场中获得 **PT** 还是 **LP**。
6. 检查交易信息，然后批准并确认。

## 到期前展期

你不必等到到期。提前展期可以避开集中迁移的高峰，让资金持续投入使用。

这一操作没有单独的表单。前往你想转入的市场，发起一笔普通兑换，并把现有的 **PT** 或 **LP** 选为输入资产即可。仪表板上的展期按钮只在市场到期后才会出现。

*请注意，提前展期是按当前市场价格卖出 PT，而不是按面值兑换，因此退出价格取决于原市场当时的 Implied APY。*

## 解读交易预览

* **Effective Fixed APY** 是扣除价格影响和手续费后你实际锁定的利率。判断这笔交易时应看这个数字，而非市场页面显示的 Fixed APY。
* **Implied APY Change** 显示你这笔交易对目标市场利率的影响幅度。变动过大说明流动性不足。
* **Min. Received** 是滑点设置所保证的最低到手数量。

## 选择目标市场

* 转入「同类市场」不会改变你的底层资产和风险敞口，只是延长到期日。转入其他资产则意味着承担该资产的风险。
* 下单前先查看**流动性**。池子过浅会使实际的 Effective Fixed APY 明显低于页面显示的利率。
* 到期日越长，锁定利率的时间也越长；若利率随后上升，这对你不利。
* 选择展期为 **LP** 而非 PT 时，会按新池子当时的 PT/SY 比例入池，赚取的是兑换手续费和激励，而不是固定利率。

## 手续费

展期需支付转入目标市场时的标准 [PT 交易手续费](../ProtocolMechanics/Mechanisms/Fees)以及燃料费，没有额外的展期费用。先兑换已到期的 PT、再单独买入新市场，所付的交易手续费相同，但需要更多笔交易。
